# JobFlow Phone MVP
This version is packaged as an installable Progressive Web App (PWA).
It includes the calendar, clients, jobs, quotes, local saved data, mobile UI, multi-week jobs, weekend option, PDF attachment filenames, and printable quote PDFs.

IMPORTANT: A browser cannot publish this app to the internet or provide true cloud sync by itself. For an online multi-device version, deploy these files to HTTPS hosting and add a database/authentication/file-storage backend.
